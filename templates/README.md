## 🚀 快速使用

### 1. 选择模板

根据您的 Agent 类型，选择对应的模板文件。

### 2. 复制模板

```bash
# 例如，复制 Python Agent 模板
cp templates/python/basic_agent.py your_project/your_agent.py
```

### 3. 修改配置

根据您的需求修改模板中的配置。

### 4. 运行

```bash
python your_agent.py
```
